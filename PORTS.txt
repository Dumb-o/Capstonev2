================================================================================
PORT ASSIGNMENTS
================================================================================

| Service               | Port  | Protocol  | Description                    |
|-----------------------|-------|-----------|--------------------------------|
| PostgreSQL            | 5432  | TCP       | Main database                  |
| Redis                 | 6379  | TCP       | Session store & caching       |
| IPFS API              | 5001  | HTTP      | IPFS node API                  |
| IPFS Gateway          | 8080  | HTTP      | IPFS content gateway           |
| Backend API           | 8000  | HTTP      | FastAPI server (main)          |
| Backend Docs          | 8001  | HTTP      | FastAPI Swagger UI             |
| Frontend Dev          | 3000  | HTTP      | React development server      |
| Admin Frontend Dev    | 3001  | HTTP      | React admin panel (admin mode)|
| Hardhat/Local Node    | 8545  | HTTP      | Ethereum local network RPC    |
| Hardhat/WS            | 8546  | WebSocket | Ethereum local network WS     |

ENVIRONMENT VARIABLES REFERENCE
================================================================================

POSTGRES_DB=freeledger
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379

# IPFS
IPFS_HOST=localhost
IPFS_PORT=5001

# Backend

# Frontend (dev)
REACT_APP_API_URL=http://localhost:8000/api
REACT_APP_IPFS_GATEWAY=http://localhost:8080

# Blockchain (Hardhat Local)
REACT_APP_BLOCKCHAIN_RPC=http://localhost:8545
REACT_APP_CHAIN_ID=31337

================================================================================
DOCKER PORT MAPPINGS
================================================================================

In docker-compose.yml:

  postgres:
    ports:
      - "5432:5432"

  redis:
    ports:
      - "6379:6379"

  ipfs:
    ports:
      - "5001:5001"  # API
      - "8080:8080"  # Gateway

  backend:
    ports:
      - "8000:8000"
      - "8001:8001"  # Swagger docs

================================================================================
NOTES
================================================================================
- Default Hardhat chain ID: 31337 (localhost)
- For production, change RPC URLs to Infura/Alchemy
- JWT expiration is in seconds (3600 = 1 hour)
- IPFS gateway is read-only; uploads go through backend API
