P01 — Async Blockchain Service, Milestone On-Chain Anchoring, and Dispute Blockchain Notification
===============================================================================================

Date: 2026-06-15
Author: Pawan Poudel

Steps to reproduce
------------------

1. Ensure Python 3.12+ is available (this test uses `python3.12` on macOS).

2. Create a virtual environment and install test dependencies:

       python3.12 -m venv /tmp/testvenv
       /tmp/testvenv/bin/pip install pytest pytest-asyncio httpx sqlalchemy aiosqlite \
           pydantic-settings python-jose passlib bcrypt eth-account web3 redis fastapi \
           uvicorn python-multipart greenlet

3. From the project root, set the database URL to SQLite (avoids needing PostgreSQL)
   and run the test suite:

       cd /Users/pawanpoudel/Downloads/Capstonev2-bijee-frontend
       DATABASE_URL="sqlite+aiosqlite:///:memory:" PYTHONPATH=backend \
           /tmp/testvenv/bin/pytest tests/backend/test_p01_async_blockchain.py -v \
           -p no:cacheprovider --override-ini="asyncio_mode=auto"

   (The file tests/backend/test_p01_async_blockchain.py is the test input.)

4. Expected result: all 9 tests pass (5 unit + 4 integration).

Input: test file (tests/backend/test_p01_async_blockchain.py)
--------------------------------------------------------------

The test file covers:

  P0.1 — Async blockchain service:
    • test_blockchain_submit_milestone_on_chain   — submitMilestone called via to_thread
    • test_blockchain_raise_dispute_on_chain      — raiseDispute called via to_thread
    • test_blockchain_resolve_dispute_on_chain_refund   — refundDispute called
    • test_blockchain_resolve_dispute_on_chain_release   — releasePayment called
    • test_blockchain_helpers                     — to_wei/from_wei/calculate_fee pure funcs

  P0.2 — Milestone on-chain anchoring:
    • test_submit_milestone_triggers_on_chain     — POST /api/contracts/{id}/milestones/0/submit
                                                    calls contract_service → submit_milestone_on_chain

  P0.3 — Dispute blockchain notification:
    • test_create_dispute_triggers_on_chain       — POST /api/contracts/{id}/disputes
                                                    calls raise_dispute_on_chain
    • test_admin_resolve_dispute_refund_triggers_on_chain  — POST /api/admin/disputes/{id}/resolve
                                                             calls refundDispute path
    • test_admin_resolve_dispute_release_triggers_on_chain — POST /api/admin/disputes/{id}/resolve
                                                             calls releasePayment path

  Unit tests mock web3 at the module level (get_web3 / get_contract).
  Integration tests use FastAPI TestClient (httpx.AsyncClient + ASGITransport),
  override DB dependency with SQLite in-memory, and patch blockchain functions
  at their import site (app.services.contract_service, app.routers.disputes,
  app.routers.admin) to verify correct arguments are passed.
