### P2.1 — CORS Hardening

File: `backend/app/config.py` (modified)

Added `cors_origins: list[str]` setting with dev defaults:
  - http://localhost:3000 (frontend dev)
  - http://localhost:3001 (admin frontend dev)
  - http://localhost:8000 (backend API / Swagger)

File: `backend/app/main.py` (modified)

Replaced `allow_origins=["*"]` with `allow_origins=settings.cors_origins`.
For production, set `CORS_ORIGINS='["https://freeledger.example.com"]'` in `.env`.

---

### P2.2 — Input Sanitization (XSS Prevention)

File: `backend/app/utils/sanitizer.py` (new)

Provides two Pydantic-v2 annotated types:
  - `SanitizedStr` — strips HTML tags, blocks `javascript:`/`data:`/`vbscript:` URIs,
    removes `on*=` event handlers from required text fields
  - `SanitizedOptionalStr` — same but allows `None`

File: `backend/app/schemas/schemas.py` (modified)

Applied `SanitizedStr` / `SanitizedOptionalStr` to all user-input text fields:
  - `UserUpdate`: username, bio, headline
  - `EmailRegisterRequest`: username
  - `JobCreate` / `JobUpdate`: title, description
  - `ProposalCreate`: cover_letter
  - `ContractCreate` / `AdminContractCreate`: title, description
  - `MilestoneDef`: description
  - `MilestoneSubmit`: notes
  - `MilestoneReject`: reason
  - `DisputeCreate` / `AdminDisputeCreate`: reason
  - `DisputeResolve`: notes
  - `MessageSend`: content
  - `AdminUserCreate`: username
  - `AdminJobCreate`: title, description
  - `AdminProposalCreate`: cover_letter

### P2.3 — Integration Tests

File: `tests/backend/test_integration.py` (new)

Two end-to-end integration tests that exercise the full API stack (blockchain
mocked, real SQLite-in-memory DB, real Pydantic validation):

1. `test_full_contract_lifecycle`:
   - Create job (client) → Submit proposal (freelancer) → Accept proposal
     (auto-creates contract) → Both sign → Fund (mock) → Submit milestone
     (mock) → Approve milestone (mock) → Contract completed

2. `test_dispute_lifecycle`:
   - Create job → Proposal → Accept → Both sign → Fund → Raise dispute
     (mock on-chain) → Contract disputed → Admin resolves with refund
     (mock on-chain) → Contract cancelled
